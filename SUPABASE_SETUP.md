# إعداد Supabase

الموقع يعمل كتجربة محلية فورًا. لجعل الأسماء والإنجازات والصور مشتركة بين جميع الأجهزة ودائمة، شغلي هذا في SQL Editor:

```sql
create table if not exists public.space_participants (
 id text primary key,
 name text not null,
 grade text not null,
 actions jsonb not null default '[]'::jsonb,
 created_at timestamptz default now()
);
create table if not exists public.space_gallery (
 id bigint generated by default as identity primary key,
 participant_id text,
 name text not null,
 grade text not null,
 activity text not null,
 image_url text not null,
 created_at timestamptz default now()
);
alter table public.space_participants enable row level security;
alter table public.space_gallery enable row level security;
create policy "space_read" on public.space_participants for select to anon using (true);
create policy "space_insert" on public.space_participants for insert to anon with check (true);
create policy "space_update" on public.space_participants for update to anon using (true) with check (true);
create policy "gallery_read" on public.space_gallery for select to anon using (true);
create policy "gallery_insert" on public.space_gallery for insert to anon with check (true);
grant select,insert,update on public.space_participants to anon;
grant select,insert on public.space_gallery to anon;
```

ثم من Storage أنشئي Bucket باسم:
space-participations

واجعليه Public، وأضيفي سياسة تسمح للـ anon برفع الصور. الموقع يقبل صورًا فقط وبحد أقصى 5MB.
